MT4 MT5 Library Manager PRO

Guide d'installation sur Windows 10 et 11 (64 bits) — environ 2 minutes

Installation

1

Ouvrez ce dossier d'installation (clic droit sur le fichier .zip → « Extraire tout… »). Il contient :

  • MT4-MT5-Library-Manager-PRO-…-Windows-Setup.exe — l'installateur ;
  • Guide d'installation Windows.pdf — ce guide.
2

Double-cliquez sur l'installateur (…-Windows-Setup.exe).

Windows affiche peut-être « Windows a protégé votre ordinateur » : l'application n'est pas signée (la signature est payante). Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

3

Suivez l'assistant : « Suivant », cochez si vous voulez une icône sur le Bureau, puis « Installer ». Aucun mot de passe administrateur n'est demandé : l'application s'installe pour votre compte seulement.

4

Lancez l'application depuis la dernière page de l'assistant, le menu Démarrer ou l'icône du Bureau.

Premier pas : écran « Mes dossiers » → « Ajouter les dossiers MetaTrader trouvés… » : l'application propose les dossiers MQL4 et MQL5 de vos MetaTrader (AppData\Roaming\MetaQuotes\Terminal…). Cochez ceux à analyser, puis « Tout analyser ».

Bon à savoir

  • Vos fichiers ne sont jamais modifiés par l'analyse : tout est lu, rien n'est écrit dans vos dossiers. Rien n'est envoyé sur Internet.
  • Ce que vous supprimez va dans la Corbeille de Windows : récupérable avec « Remettre en place » (écran Quarantaine, onglet Corbeille) ou depuis la Corbeille (clic droit → Restaurer). Les disques réseau n'ont pas de Corbeille : rien n'y est supprimé.
  • Les fichiers OneDrive non téléchargés ne sont pas lus (sinon Windows les téléchargerait).
  • Vos données (base, sauvegardes) : %APPDATA%\MT4MT5LibraryManagerPro.

Mise à jour et désinstallation

  • Mettre à jour : lancez l'installateur de la nouvelle version ; vos données sont gardées.
  • Désinstaller : Paramètres → Applications → « MT4 MT5 Library Manager PRO » → Désinstaller (vos données restent dans %APPDATA%, supprimez ce dossier si vous le souhaitez).
Application non signée. Testée automatiquement sur Windows (GitHub) à chaque version.
